
# Documentación Técnica

## Lenguaje
El sistema está desarrollado en Python.

## Estructuras de programación
- Condicionales para validar operaciones.
- Bucles para recorrer registros.
- Listas para almacenar información.
- Diccionarios para representar registros.
- Cadenas para procesar datos.

## Funciones reutilizables
El módulo services.py contiene funciones
como:

- records(): obtiene registros.
- add(): agrega información.
- replace(): reemplaza registros.
- seats(): consulta los asientos.
- sell(): registra una venta.

## Almacenamiento
El módulo storage.py proporciona funciones
para cargar y guardar información.

## Organización modular
El proyecto separa las operaciones principales,
los servicios y el almacenamiento para facilitar
su mantenimiento.
