
# Plan de Pruebas del Sistema

## Objetivo
Verificar el funcionamiento de los módulos
del sistema de gestión de buses.

## Casos de prueba

### Prueba 1: Registro de pasajeros
Ingresar los datos de un pasajero y
comprobar que se guarden correctamente.

### Prueba 2: Validación de DNI
Ingresar un DNI incorrecto o repetido
y verificar que se rechace el registro.

### Prueba 3: Consulta de rutas
Consultar las rutas y comprobar que
se muestre la información disponible.

### Prueba 4: Disponibilidad de asientos
Consultar un bus y verificar que
se identifiquen los asientos ocupados.

### Prueba 5: Venta de pasajes
Registrar una venta con un pasajero válido,
una ruta existente y un asiento disponible.

### Prueba 6: Persistencia de datos
Guardar información, reiniciar el programa
y comprobar que los registros se conserven.

## Registro de resultados
Los resultados de cada prueba deben anotarse
después de ejecutarla, indicando si fue
satisfactoria o si presentó errores.

## Cierre
El sistema deberá considerarse listo para
entrega después de completar las pruebas
y corregir los problemas detectados.
