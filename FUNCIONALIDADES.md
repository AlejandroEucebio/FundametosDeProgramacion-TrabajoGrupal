
# Funcionalidades del Sistema de Buses

## Objetivo
Gestionar la información de buses, rutas,
pasajeros y ventas de pasajes.

## Módulos del sistema
- main.py: controla las opciones principales.
- login.py: contiene funciones de acceso.
- iniciar.py: archivo de inicio del sistema.
- services.py: gestiona pasajeros, rutas,
  asientos y ventas.
- storage.py: permite cargar y guardar datos.

## Funcionalidades
1. Registro de pasajeros.
2. Consulta de rutas disponibles.
3. Gestión de buses.
4. Visualización de asientos disponibles.
5. Registro de ventas de pasajes.
6. Conservación de datos mediante archivos.
